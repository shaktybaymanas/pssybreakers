КАК СДЕЛАТЬ СВОЙ КОММИТ

1. Дождитесь, пока предыдущий участник отправит свою часть на GitHub (push). Для части 1 ждать не нужно.
2. Полностью распакуйте этот ZIP в отдельную папку, не внутрь сайта.
3. Запустите APPLY.cmd. Нужны Git и интернет.
4. Нажмите Enter: скрипт создаст отдельную копию репозитория в Документах. Или укажите свою чистую копию на ветке main.
5. Скрипт обновит её и подготовит ТОЛЬКО эту часть для коммита. При ошибке остановитесь и прочитайте сообщение.
6. Откройте появившийся КОМАНДЫ.txt. Выполните команды по очереди в PowerShell. git diff --cached показывает изменения; нажмите q, чтобы выйти из просмотра.
7. После успешного git push сообщите следующему участнику.

git add . не нужен: APPLY.cmd уже добавляет только файлы вашей части.
Коммит и push скрипт не выполняет. Git использует ваши обычные имя/email и доступ к GitHub. Если Git просит имя/email, настройте свои данные, не данные другого участника. У каждого должен быть доступ на запись в репозиторий команды.

ЧТО ПРОВЕРИТЬ
Прочитайте изменения в git diff --cached. При наличии Node.js 22.7+ выполните в папке сайта: node --test tests/*.test.mjs
После всех четырёх частей откройте index.html через Live Server или START-SITE.cmd. Проверьте фильтры в общем списке и в профиле автора.

ВАЖНО ДЛЯ АЛИШЕРА
В старой рабочей папке уже лежит весь готовый сайт. Не выполняйте в ней git add . и общий коммит до завершения этих четырёх частей. Применяйте свою часть в отдельной копии через APPLY.cmd. Исходные файлы сохраняются.
