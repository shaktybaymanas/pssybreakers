Практика JavaScript / 01

Работа с элементами и кодами

Нажимайте кнопки, чтобы изменить текст, создать и удалить элементы. Затем нажмите на изменяемый абзац.

1. Найти по ID и изменить текст

Найдите элемент с ID greeting и замените его текст на «Привет, мир!».

Этот текст нужно изменить.

2. Создать новый div

Создайте div с классом new-div и текстом «Я новый элемент». Добавьте его в конец body.

Элемент появится внизу страницы, после подвала.

3. Удалить элемент

Удалите элемент с классом old-element.

Я старый элемент. Меня нужно удалить.

4. Изменить абзац по нажатию

Создайте абзац «Это изменяемый абзац». По нажатию измените цвет текста и размер шрифта.

Нажмите на абзац или выберите его клавишей Tab и нажмите Enter. Повторное нажатие вернёт исходный вид.
